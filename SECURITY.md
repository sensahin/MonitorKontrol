# Security policy

## Supported versions

Security fixes target the latest release and the `main` branch.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/sensahin/MonitorKontrol/security/advisories/new)
for vulnerabilities or reports containing sensitive details. Do not publish a
security vulnerability as a public issue before a fix is available.

For ordinary bugs that do not expose sensitive information, open a regular
GitHub issue with the macOS version, Mac model, connection route, and monitor
model. Remove serial numbers and unrelated diagnostic data first.
